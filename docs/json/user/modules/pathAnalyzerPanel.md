# Path Analyzer Panel

The Path Analyzer panel is a standalone tool for analyzing what's required to reach any region in the game. Unlike the integrated "Analyze Paths" feature in the [Regions](regions.md) panel, this dedicated panel lets you analyze a path to any region by typing its name.

## Usage

1. Type a region name into the input field (e.g., "Lost Woods").
2. Click **Analyze Paths** or press **Enter**.
3. The results appear below, showing the possible paths and requirements to reach that region from the start.

During analysis, the button text changes to "Analyzing..." and the input field becomes read-only until the analysis completes.

## Results

The analysis output shows which items and conditions are needed to reach the target region, considering all possible routes through the game world.
