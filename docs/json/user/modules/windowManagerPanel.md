# Window Manager Panel

The Window Manager opens and manages separate browser windows that connect back to the main application.

## Opening a Window

Choose content in two ways:
1. **Known pages dropdown** — Select from predefined pages:
   - "Text Adventure (Standalone)" — A standalone text adventure in a separate window
   - "Window Base" — A basic connection and heartbeat demo
2. **Custom URL** — Type any URL into the input field.

Click **Open Window** (or press Enter) to launch the content in a new browser window.

## Closing

Click **Close All** to close all connected windows.

## Status

The panel shows:
- **Operation status** — Success or error messages.
- **Connected Windows** — A list of all windows that have established a connection to the main application, with their IDs and connection times.

## vs. Iframe Manager

The Window Manager works like the [Iframe Manager](iframeManagerPanel.md) but opens content in separate browser windows instead of embedded iframes. This is useful when you want the content on a different monitor or in a larger view.
