# Dungeons Panel

The Dungeons panel shows all the major dungeon areas in the game, letting you track boss requirements and see which dungeons you can access with your current items.

## Controls

- **Search** — Filter dungeons by name using the search box at the top.
- **Expand All / Collapse All** — Toggle all dungeon blocks open or closed.

## What You See

Each dungeon appears as a collapsible block showing its region count. Expand a dungeon to see:

- **Regions** — The areas that make up the dungeon. Each region name is a clickable link that jumps to that region in the [Regions](regions.md) panel.
- **Bosses** — Each boss is listed with its defeat rule shown as a logic tree. Items you have are highlighted green; items you're missing are red.

The logic trees update automatically as your inventory changes. When you collect a required item, the corresponding node turns green immediately.

## Navigation

Click any region name inside a dungeon block to navigate to it in the Regions panel. Other panels can also send you here — when they do, the target dungeon automatically expands and scrolls into view with a brief highlight.
