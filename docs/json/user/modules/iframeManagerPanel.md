# Iframe Manager Panel

The Iframe Manager controls what content is loaded into [Iframe Panel](iframePanel.md) instances.

## Loading Content

Choose content in two ways:
1. **Known pages dropdown** — Select from predefined pages:
   - "Text Adventure (Standalone)" — A standalone text adventure running in an iframe
   - "Iframe Base" — A basic connection status demo
2. **Custom URL** — Type any URL into the input field.

Click **Load Iframe** (or press Enter) to load the selected URL into an available Iframe panel.

## Unloading

Click **Unload All** to clear all active Iframe panels.

## Status

The panel shows:
- **Operation status** — Success or error messages after load/unload operations.
- **Connected Iframes** — A list of all iframe instances that have successfully established a connection back to the main application, with their IDs and connection times.
